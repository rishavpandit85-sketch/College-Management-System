# College Management System

A Java-based College Management System developed to demonstrate core Object-Oriented Programming (OOP) concepts.

## Features

- Student management
- Professor management
- Administrative staff management
- Person-based inheritance
- Method overriding
- Constructor overloading
- Polymorphism

## OOP Concepts Used

- **Encapsulation** – Data is organized within classes.
- **Inheritance** – Student, Professor, and AdminStaff inherit from Person.
- **Polymorphism** – Different classes provide their own implementation of `showDetails()`.
- **Method Overriding** – Subclasses override methods from the parent class.
- **Constructors** – Objects are initialized using constructors.
